### Hey, I'm Morrow. 👋

I'm a **19-year-old full-stack developer** passionate about transforming creative ideas into thoughtfully engineered software.

My interests span **modern web development, backend architecture, intelligent agents, artificial intelligence, and open-source engineering**.

I enjoy creating complete software systems, from designing intuitive interfaces to implementing reliable backend services and deploying applications into production.

I'm particularly interested in **AI agents, multi-agent collaboration, LLM applications, real-time communication, and system architecture**.

For me, programming is more than writing code. It's a way to explore ideas, solve meaningful problems, and continuously challenge my understanding of technology.

> Great software should not only work. It should be thoughtful, elegant, and meaningful.
